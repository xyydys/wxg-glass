# WeChat Liquid Glass · TEST4 FIX39

版本 `0.4.39-test4fix39`，基于 FIX38。18 个源文件与 FIX38 逐字节相同（`tools/audit_fix39_scope.py`）。

## 材质覆层太透明（冷启动、透镜落下前）

这两处其实是同一个问题。Metal 叠加层还没画出来（冷启动），或者在点击动画期间被隐藏时，底栏的材质由一层系统渲染的“替身”顶替。之前这层替身只用了“材质颜色 × 不透明度”，而着色器实际画的是：
- 关闭“清透材质”时，比设置的不透明度**强 22%**；
- 开启“边缘减弱”时，越靠近轮廓越淡（1 − 0.82·edge²，edge 按轮廓内距离做 smoothstep）。

所以替身在中间区域明显更透明。现在替身用完全相同的强度；边缘减弱按胶囊（或圆角矩形）的精确距离逐像素算成一张遮罩（按尺寸缓存）。另外，这层替身的大小、颜色变化不再带隐式动画，不会再跟不上底栏。Metal 有没有画出来，看到的材质都一样。

## 按住拖动的形变

FIX37 的速度映射太早饱和（300 pt/s 时已经 80%），稍快一点就拉到最长。现在改为与手速成比例：300 pt/s 约 28%，600 约 49%，1000 约 67%，2000 约 89%。拉伸范围、可以比底栏略矮、急停的灵敏度都保留；形变弹簧放慢一些，介于 FIX36 和 FIX37 之间。

## 切换动画：更慢、更柔和、不完全浮起

- 浮起：约 150 ms，ease-in-out，只浮起到按压透镜的 **62%**，不再变成静止按压的完整大小；
- 滑行：更柔和、不过冲的弹簧（刚度 190 / 阻尼 26），接近目标时略微下沉；
- 落下：最后约 0.3 秒缓缓沉入胶囊，**去掉了压扁回弹**（就是你说落下时像在跳的那一下）；
- 总时长约 0.62 秒；
- 颜色：浮起最高时选中胶囊色完全透明，下沉时逐渐加回；描边和放大跟着同一条曲线；
- 材质与 FIX37 相同。

## 刚启动时切换慢

诊断显示，刚启动后第一次切到“我”：微信自己的切换调用用了 212 ms，之后又忙了 143 ms（页面第一次加载）；我们这边是刷新 10 ms、动画准备 7 ms。所以慢主要在微信，这部分改不了。FIX38 的动画很快就结束了，等待就显得特别明显；新的动画更慢，能和这段等待重叠一些。

另外，点击动画的图层和折射毛玻璃现在启动 3 秒后空闲时就预先建好，之后每次点击直接复用，不再每次重建，刚启动后的头几次点击少一些准备工作。
