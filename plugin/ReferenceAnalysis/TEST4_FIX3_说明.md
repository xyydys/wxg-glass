# WeChat Liquid Glass · TEST4 FIX3

版本 `0.4.3-test4fix3`，基于 TEST4 FIX2 的两端式输入修补。保留原来的材质参数、玻璃外形公式和三端式输入实现。本轮不扩大导航、底栏或菜单适配范围。

## 已定位的问题与修改

新上传的两个分卷有连续的 75 条事件，7 份输入快照全部保存成功，编码修复和字段错误均为 0。设备是 iPhone XS Max、iOS 15.7、微信 8.0.73。三端式的局部树达到节点上限，但所需输入控件和动作已抓到，不需要为本次修补重抓。

旧两端式优先选择“存在的听写按钮”。这份低系统日志证明：键盘收起时 `MMGrowDictationIconView` 仍然存在，因此原生语音模式切换被它挤掉。现在依据输入状态选择右侧功能：

| 当前状态 | 两端式最右侧 |
| --- | --- |
| 未编辑、键盘收起 | 切换到按住说话，包括保留草稿时 |
| 正在编辑、输入为空 | 原生语音转文字 |
| 正在编辑、有文字 | 原生发送 |
| 已进入按住说话 | 切回文字输入 |

动作均绑定微信现有控件。微信没有提供可用听写动作时，保留可用的语音模式入口；没有有效目标时不制造点击行为。按住说话的实际录音、滑动取消及松开发送仍由原生 `_recordButton` 和长按识别器处理。语音模式隐藏文字编辑器时保留输入适配器和胶囊，玻璃放到真实录音控件下方。

日志还显示旧代码对编辑器宽度的修改会被 `MMGrowTextView` 重新布局覆盖：实际文字区重新延伸到右侧表情按钮下方。本版改为给原生 grow 容器分配可用宽度，预留表情和右侧动作列；不直接写 UITextView 的 frame、inset、TextKit 容器或光标。保留原生内容区的纵向位置和高度，宽度变更后由原生布局文字与光标。

切换编辑、空输入/有文字、文字/语音时立即重新绑定；尺寸恢复只记录微信改变的部分，防止插件自己的横向修正被当作原生尺寸缓存到三端式或下一页。

## 保留范围

相对 FIX2，运行源码只修改 `WXGInput.m` 并增加 `WXGInputPolicy.h`；`WXGHost.m` 和 `WXGSettings.m` 只有版本文字变更。三端式适配器、TEST9 折射/模糊、独立透镜、LUMI 展开形变、底栏、导航、主题、背景采样与既有性能优化保持 FIX2 源码。逐文件校验见 `Validation/fix3_scope.json`。FIX2 历史说明见 `ReferenceAnalysis/TEST4_FIX2_说明.md`。

## 安装与自编译

替换旧主插件，rootful 或 rootless deb 只安装一种，也可替换同名 arm64 dylib，然后完全退出并重开微信。保留 `optics.test4` 材质设置，无需重新调参。探针继续使用 WGP3.2，本包不更新探针。

Theos 工程最低 iOS 13：

```sh
export THEOS=/opt/theos
./build.sh rootless
# 有根环境使用 ./build.sh rootful
```

本轮设备回测只需关注：收起键盘后右侧能切入语音；中间长按能录音并滑动取消；右侧切回文字，空框能语音转文字，有文字能发送；长文本不盖住表情和右侧按钮；切回三端式能恢复原布局。已有的转场、菜单和置顶项日志不用重新采集。

## 验证界限

数值回归、源代码比对、Apple SDK 语义检查与实际 arm64 编译/签名结果见 `VALIDATION.md`。没有 iPhone 运行环境；微信私有布局、中文输入法、录音权限、实际录音/取消、Metal 和视觉效果尚待真机确认。编译通过不代表这些交互已经真机验证。此前的转场、主题和首页流畅度仍是 FIX2 的实现，本轮不宣称它们已得到新的设备验收。
