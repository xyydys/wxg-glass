# WeChat Liquid Glass · TEST4 FIX48

版本 `0.4.48-test4fix48`，基于 FIX47。14 个源文件与 FIX47 逐字节相同（`tools/audit_fix48_scope.py`）。

## 透镜两端：按 iOS 26 的瞬间收敛

你观察到的规则：透镜轮廓与底栏上 / 下边框的交点，一离开底栏的直线段、进入两端的圆弧，透镜这一端的折射就降到 0。现在按这个规则计算：
- 每次都算出透镜两端各自与底栏上下边框的交点，看它们是否已到达底栏圆弧开始的位置；
- 到达的那一端，折射宽度在 1.5pt 内降到 0（只保留 0.5pt 的细边，用来显示透镜边框），透镜内的形状不再被折射；
- 另一端和上下边不受影响；
- 在底栏中段，透镜两端都在直线段上，规则与 FIX44 / FIX21 完全相同（测试逐值验证）；
- 静止时（透镜不比底栏高）不受影响。

透镜下的毛玻璃（网格）和透镜里的底栏用同一个函数。为了让底栏中段完全不变，网格里底栏两端的截断位置也挪到了底栏圆弧半径之外。

FIX47 的“底栏内 / 外”判断（每个点各自判断，收敛不够）已被这条规则替换。内缩约 45° 的过渡保留。
