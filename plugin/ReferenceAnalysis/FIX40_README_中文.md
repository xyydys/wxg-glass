# WeChat Liquid Glass · TEST4 FIX40

版本 `0.4.40-test4fix40`，基于 FIX39。18 个源文件与 FIX39 逐字节相同（`tools/audit_fix40_scope.py`）。拖动形变与 FIX39 完全相同。

## 冷启动底栏太透明：彻底换一种做法

FIX35–39 一直是：材质覆层平时由 Metal 画，Metal 还没画出来或被临时隐藏时，换成一层系统渲染的“替身”。只要有替换，就可能在某个时刻对不上（替身的强度、显示或隐藏的时机）。FIX39 把强度对齐了，冷启动仍然偏透明，说明问题出在“什么时候显示哪一层”上，而不是强度。

现在不再替换：同步模式下，底板的材质覆层**永远**是这层系统渲染的图层（颜色、强度、边缘减弱都与原着色器公式一致），Metal 的底板一遍只画图标。所以：
- 冷启动从第一帧起就是目标材质，不依赖 Metal 是否就绪、主线程是否空闲；
- Metal 第一帧出现前后，材质不会变化；
- 点击动画期间隐藏 Metal 叠加层时，材质也不变（落回前那一下“忽然变透明”的现象来源于此）。

透镜内部的材质仍由透镜那一遍每帧绘制（它本来就跟着透镜动）。改了材质设置后，玻璃在下一帧检测到配置变化，立即更新这层图层。

## 点击切换：iOS 26 的节奏

- 滑动比 FIX39 更慢（弹簧刚度 120 / 阻尼 21，约 0.4 秒到 93%）；
- 透镜在滑动中逐渐变大，在接近终点时（整段的约 70%）达到静置按压透镜的 **90%**，此时选中胶囊色完全透明，透镜最透明；
- 然后**快速落下**（约 90 ms，ease-in）成胶囊，选中色迅速回来，最后短暂收尾，不回弹；
- 总时长约 0.64 秒；描边、放大跟随同一条曲线；
- 折射毛玻璃按 90% 浮起预先建好并复用。
