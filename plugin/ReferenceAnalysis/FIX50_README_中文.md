# WeChat Liquid Glass · TEST4 FIX50

版本 `0.4.50-test4fix50`，基于 FIX49。

## 透镜：回到 FIX26–FIX43 的样子

FIX44 之后我在透镜上做的所有尝试（透镜里的底栏跟着折射、45° 接法、两端收敛等）全部撤回：
- 着色器与 **FIX43 逐字节相同**；
- 透镜光学（`WXGLensOptics.h`）、网格（`WXGMeshRefraction.h`）、内缩（`WXGOptics.h`）与 FIX43 / FIX44 逐字节相同；
- `WXGGlassView.m` 与 FIX44 只差一行版本号。

我核对过：透镜这部分从 FIX26 到 FIX43 基本没变。网格和透镜光学的头文件逐字节相同，着色器的透镜分支只多了你后来认可的两处：FIX36 的透明透镜（伸出底栏的部分不加材质）和 FIX27 的边框渐隐。所以现在透镜的效果就是 FIX26 前后那时的样子：
- 透镜里的底栏比外侧小（内缩），不跟着折射；
- 两端也不会再把底栏卷进去，因为透镜里的底栏本身不折射，折射的只是后面的页面。

点按动画、冷启动、拖动形变等 FIX44 及以前的改动都保留。

## 钱包顶部

我量了你的截图：导航栏后面那一条是 (17,17,17)，和页面最下面空白处的颜色完全一样，那里其实已经没有任何单独的底色了。

你看到的“背景”实际是：钱包（微信支付的 Kinda 页面）的列表从导航栏底边开始，并且在那里被裁掉。往上滑时，行到了导航栏底边就消失，不像其它页面那样从玻璃按钮下面穿过去，于是顶部看起来像一块不透明的栏。

现在只在 Kinda 页面上，让这个列表以及从导航栏底边开始的那几层容器不再裁掉超出顶部的内容，上滑的行就能显示到玻璃导航栏下面。只改裁剪，不改位置和触摸，离开页面时恢复。

如果 Kinda 的列表是“滑出去就回收”的那种，这一招就看不到效果。这时诊断里的 `kindaProbe` 会列出列表那几层：类名、位置、是否裁剪，以及列表的滚动位置、内容高度、行数，下一步据此处理。FIX48 那条“导航栏下方色带”的规则已删除：那条 57pt 其实是“零钱”那一行，规则也从未作用过。
