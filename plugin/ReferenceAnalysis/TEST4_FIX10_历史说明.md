# WeChat Liquid Glass · TEST4 FIX10

版本 `0.4.10-test4fix10`，基于 FIX9 单独修改。主要处理主线程采样、聊天离开时的转场干扰、半返回底栏和视频号按钮。保留原参数；没有重设折射、模糊、透镜公式或输入栏布局。

## 本次日志证据

6 个分卷属于两次 WGP4.3 录制，均为 iOS 26.6 / 微信 8.0.73 / 120 Hz 屏幕。没有低设备卡死时的线程栈，不能据此断言其唯一原因。

- 高设备也记录到背景采样约 57.65、107.31 ms 的主线程峰值；GPU 通常明显短于这项。旧实现仍在主线程对原生根图层同步栅格化。
- 聊天离开时的转场记录约 3–11 ms 就结束，正常进入聊天约 0.59 秒。原始 pop 参数仍是 animated=YES。旧日志未区分 UIKit completion 与插件 viewDidAppear 提前收尾，不能只凭这个时长确定 UIKit 动画时长。
- 视频返回记录中，原生底栏 model x=-132、presentation x=-41.432。旧算法把终点当基准，恰好算出了插件实际错误位置 x=79.1321。

精简证据见 `Validation/fix10_log_findings.json`。原始聊天日志不打包进工程。

## 修改

1. 背景采样复制一棵无 UIView delegate、无原生动画的独立绘制图层树，在串行后台队列栅格化。主线程不再隐藏原生图层或调用原生根图层 renderInContext。只保留一个在途任务；过期页面和尺寸结果丢弃。复制时逐层检查 4 ms / 1600 节点预算，超出则保留既有画面，不同步补抓。
2. 每显示回调最多给两个需要更新的玻璃复制背景纹理，按最久未更新者优先，避免一张新背景同时触发所有按钮的全分辨率复制。慢复制增加等待时间；隐藏页面释放高斯临时纹理，保留自己的原始背景帧及视图。
3. UIKit push/pop 调用栈内不重建、重新挂载导航或重排输入。取消 viewDidAppear 提前结束转场的分支，以 coordinator 的完成/取消为准。全部导航转场期间沿用已有纹理，继续跟随原生动画。
4. 底栏使用稳定主页坐标作为转场基准；用绘制 mask 隐藏原生底栏，保留 UIKit 的 alpha/hidden/transform。根覆盖层在转场容器之上，按主页真实露出区域裁剪。离开的聊天输入栏继续重施背景清理，不改变其布局或原生动作。
5. 视频号四个导航按钮保留原生原色图标、动态图片资源和模板 tint，不统一染成 labelColor。玻璃选择微信主窗口的深浅色分组，继续读同一份 TEST9 材质参数；不根据背景亮度切色。
6. 日志增加 coordinator 时长、完成来源、导航调用深度、后台采样耗时、丢弃任务数、预算退出和纹理复制名额。现有 WGP4.3 能读取这些字段，不必更换探针。

## 仍需设备验证的边界

本环境只有 iOS 交叉编译工具，不能运行微信/UIKit/Metal。已通过编译和数值检查不等于低设备卡死已排除，也不等于转场及采样像素已在手机验收。

新采样复制现有图层绘制数据，不主动驱动微信 drawRect。GPU 视频、系统 backdrop/filter、尚未提交绘制内容的自定义层可能没有可复制像素；需要确认这些内容下的折射是否完整。预算超时沿用旧帧，诊断会记录退出次数。

转场期间不更新背景。已有页面沿用自己的帧；首次进入且无缓存的玻璃，要等转场结束后的首张有效背景才能出现完整折射。这是本版优先解除转场采样争用的取舍，不是永久创建失败。

显示及透镜动画仍请求设备支持的最高 120 Hz。背景读取受串行任务、区域轮转和两个复制名额限制，并非每块玻璃每秒采样 120 次。没有降低 Metal 输出分辨率或改动高斯核。

## 安装、最短检查

编译包含 arm64 dylib、plist、rootful/rootless deb、完整工程 ZIP 和验证报告；最低 iOS 13。替换旧主插件并完全退出微信，再打开；只启用一份主插件，保留参数。arm64e 仅做语义检查，没有另附 arm64e 二进制。

先在当前能操作的高设备上、不开探针记录确认：聊天→首页、聊天→聊天设置、视频号半返回并取消，以及修改一个普通玻璃参数后视频号按钮是否跟随。低设备先不要继续勉强录制。

若仍异常，用现有 WGP4.3 只录对应动作约 10 秒。新字段在 host.sampling / host.transitionLog 中，不需要重跑所有测试。采样预算或背景缺失时，重点看 lastCopyMS、lastWorkerRasterMS、discardedJobs、pruneBudgetAborts、unbackedLayers、transitionPaused。

Theos 自行编译：

```sh
export THEOS=/opt/theos
./build.sh rootless
# 或 ./build.sh rootful
```
