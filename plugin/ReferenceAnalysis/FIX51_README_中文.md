# WeChat Liquid Glass · TEST4 FIX51

版本 `0.4.51-test4fix51`，**直接基于 FIX44**。FIX45–FIX50 里透镜和头像的改动都不带入；只保留钱包顶部那两处（FIX47 的整页底色、FIX50 的列表可画到导航栏下方）。15 个源文件与 FIX44 逐字节相同（`tools/audit_fix51_scope.py`）。

## 透镜两端：按你的方案

**透镜只在首尾两个图标之间折射和色散。** 超出第一个图标的左边缘、最后一个图标的右边缘之后，折射和色散在 6pt 内收敛到 0。
- 图标块的边缘取图标（28pt）和标题（选中字重）中较宽者的一半，和图标图集画出来的位置一致；
- 底栏中段，整个透镜都在图标范围内，**上下边、两端的效果与 FIX44 完全相同**（测试逐点验证网格逐位不变）；
- 到了底栏两端，透镜伸出最后一个图标的那部分不再折射、不再色散：透镜里的底栏末端是干净的，透镜后面的页面也不再被卷进去；
- 三处同一规则：Metal 着色器（透镜里的底栏和图标）、透镜下的折射网格、点按动画的透镜（按目标位置选网格，三种变体在预热时就建好，不会拖慢点按）。

## 45° 过渡

内缩边框与外侧边框的接法：从透镜轮廓与底栏边框相交的那一列起，水平往里算，下沉多深就在多宽的距离里完成，平均 45°。靠近透镜上下边的部分则保持 FIX44 原样（1.25pt 内缓入，按垂直距离算），所以上下边的折射带不受影响。这两点分开处理，正是 FIX47（按到轮廓的距离算，被陡峭的圆弧带成了竖直）和 FIX49（上下边一起被改掉）各自出错的地方。测试里逐点验证：沿上边与 FIX44 的内缩完全相等；两端平均斜率正好 45°。

## 透镜内底栏的取样（FIX44 的两处必要修正）

- 只被折射带弯曲，不跟着放大。FIX44 让它跟着放大，正好抵消了内缩，这就是 FIX45 时“内缩没了”的原因；
- 轮廓改为解析形状并按屏幕变化率抗锯齿，去掉 FIX44 取样距离纹理造成的锯齿。

FIX44 对透镜内底栏的分通道色散保留。
