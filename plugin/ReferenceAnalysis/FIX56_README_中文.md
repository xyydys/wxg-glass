# WeChat Liquid Glass · TEST4 FIX56

> 存档：FIX56 = FIX54 + 两端折射带收敛。用户对比后认为收敛的方向对，但“太机械、太狠”，而且 FIX54 透镜唤起胶囊时不如 FIX47，于是改为 FIX57（从 FIX47 出发，末端放松更晚、更缓）。文中的对照图在 FIX56 压缩包的 `ReferenceAnalysis/` 里。

版本 `0.4.56-test4fix56`，**基于 FIX54，只改了一处**：拖动透镜走到底栏两端时，透镜左右两侧的折射范围收窄到和上下边一样宽。FIX55 的连接曲线、末端吸入都没有带过来。

## 改了什么

- **什么时候开始**：看透镜轮廓和底栏上下边相交的那一点（交点）。交点还在底栏的直线段上时，和 FIX54 完全一样；交点一进入末端圆弧，这一侧的折射范围在 3 pt 内收窄到上下边的宽度（按 FIX49 时你的设置是 20.26 × 0.305 ≈ 6.2 pt）。左右两端对称，各管各的。
- **作用于什么**：透镜里的内部底栏，以及透过透镜看到的页面（包括色散）。这一端只有贴着透镜边约 6 pt 的一圈还在折射，离边远一点的内容不再被拉到透镜边上。透镜停到末端、盖过底栏末端时，内部底栏露出自己的圆头，和透镜边之间留出一道缝；FIX54 会把它拉到透镜边上（粘连）。
- **不作用于什么**：图标和文字仍按原来的折射范围折射，已经在折射的不会突然变形。
- 按你截图的尺寸：截图 1 的位置交点还在直线段上，和 FIX54 一样；截图 2、3、4 的位置这一端已经完全收窄。
- 透镜不比底栏高时没有交点，不收窄（比如快速拖动时透镜被压扁）。透镜上下各高出底栏 2 pt 之前是逐渐生效的，所以透镜高度变化时不会跳。

## 注意

- **只有透镜折射打开时才看得出来。** 透镜折射为 0 时，FIX56 和 FIX54 逐像素相同（模拟里核对过）。
- 只改拖动时的透镜。点按 / 按住时的透镜，以及拖到另一个标签松手后的落下动画，用的是渲染服务里的另一个透镜，和 FIX54 一样，没有收窄。
- 中段、上下边的折射、内缩、拖动手感、点按切换、冷启动、钱包、头像、置顶都和 FIX54 相同。

## 写死的参数

| 项 | 值 | 位置 |
|---|---|---|
| 收窄完成所需距离（交点进入圆弧后） | 3 pt | `WXG_END_CONVERGE`（`WXGLensOptics.h`） |
| 透镜高出底栏多少后完全生效 | 上下各 2 pt | `WXGLensEndConvergence` |
| 页面网格的收窄量 | 按 1/8 取整 | `WXGGlassView.m` |

想让它更早、更晚或更缓地收窄，直接告诉我数值。

## 诊断

`layerEvidence` 新增 `endConvergence`（左 / 右，0 是原来的折射带，1 是已收窄到上下边宽度）。
