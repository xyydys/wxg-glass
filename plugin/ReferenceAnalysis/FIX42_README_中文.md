# WeChat Liquid Glass · TEST4 FIX42

版本 `0.4.42-test4fix42`，基于 FIX41。18 个源文件与 FIX41 逐字节相同（`tools/audit_fix42_scope.py`）。拖动手感不变。

## 点击切换：按距离变化

你看到“移动像光速、落下很慢”，原因在按下的那一刻：FIX35 起，按下另一个标签时，透镜用跟手拖动的弹簧追过去，0.1 秒左右就横跨整条底栏。等你松手时它早就到了，松手后的动画只剩原地的浮起、落下，所以显得落得慢。

现在两段都按实际距离：
- **按下**（还没拖动时）：透镜沿和松手动画同一条缓动曲线滑向手指所在的标签，用时 0.16 s + 0.12 s × 标签数（一格约 0.28 秒，1→4 约 0.52 秒，比原来慢约 3 倍）；手指一旦移动超过 10pt，立即换回你满意的跟手弹簧，从当前位置接着跟；
- **松手**：系统渲染的动画按**剩余**距离计时，移动 0.14 s + 0.13 s × 剩余标签数（1→4 约 0.53 秒）；透镜在移动到一半多时（约 55%）达到静置按压透镜的 90%，最透明；落下约 90 ms（比 FIX41 快一倍），落下结束正好到达；再 50 ms 收尾；
- 如果松手时透镜已经在目标上（拖动后松手），只剩一次快速落下。

## 冷启动透明：这次先测量

FIX41 的外观（深浅色）不是原因，你的日志显示从一开始就是浅色。根据目前的代码和日志，材质层的数值、可见性、布局、层级都检查过，找不到会让它冷启动透明的路径，所以这一版不再凭推测改，而是精确测量：

启动后 1–12 秒，每 0.2 秒记录一次底栏的实际渲染状态（变化时才记一行，写在 `coldStartLog` 里，以“渲染状态”开头）：
- 底栏：是否隐藏、不透明度、尺寸、深浅色、呈现状态；
- 备用：底板、透镜、图标是否隐藏；
- 玻璃：是否隐藏、不透明度、是否在窗口里、是否激活、是否就绪、是否画过第一帧，玻璃区和裁剪区的尺寸；
- 材质层：是否隐藏、尺寸、不透明度、在兄弟图层中的位置、被纠正过几次；
- 模糊层、Metal 层是否隐藏；
- 微信原生底栏是否隐藏、不透明度。

同时加了两项保险：
- 每次布局都检查材质层是否紧贴在 Metal 层下面、所有模糊层之上，不对就纠正（并计数）；
- 底栏自带的备用材质底板一直保留到玻璃画出第一帧为止（之前在同步模式下直接隐藏了）。

请冷启动后 30 秒内导出诊断发我，我就能看到冷启动那一刻底栏到底是哪一层在显示。
