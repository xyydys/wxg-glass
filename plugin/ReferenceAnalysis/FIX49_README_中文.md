# WeChat Liquid Glass · TEST4 FIX49

版本 `0.4.49-test4fix49`，基于 FIX48，只改了一处：透镜内缩边框与外侧边框的接法。

## 为什么是“两个直角拐下来”

我按你的实际设置（底栏 63.86、透镜折射 4.21、两端折射宽度 20.26、上下比例 0.305、内缩 0.131 等）把着色器算透镜里底栏轮廓的那几步完整复算了一遍，画出了透镜端部的形状（`ReferenceAnalysis/FIX49_inset_join_simulation.png`，脚本 `tools/simulate_lens_join.py`）：
- FIX47 是按“到透镜轮廓的距离”来算内缩过渡的。可在外侧边框与透镜相交的地方，透镜轮廓是一段很陡的圆弧（约 63°），“离轮廓几 pt”在那里几乎就是一条竖线，所以 4.4pt 的下沉在大约 1pt 的水平距离内就完成了，几乎是竖直的；
- 另外，内缩是在折射之前的位置上取的，透镜上沿下面那一条恰好还没开始内缩，被折射往上拉成了沿整个上沿的一条灰带。

这两样叠在一起，就是你看到的两个直角。

## 现在

完全按你说的做：
- 从透镜轮廓与底栏边框的交点那一列开始，**水平**往里算，下沉多深就在多宽的距离内完成，平均正好 45°；
- 这个“已经接好”的形状再整体被折射（在折射后的位置上取内缩）；
- 上下边框各自算各自的交点；透镜为圆角矩形时同样适用；
- 沿上沿的那条灰带也一起消失了。

模拟图从上到下依次是：新接法未折射时（45° 斜线）、新接法折射后（一条连续的曲线贴着透镜边）、FIX47 折射后（灰带加方头）。

透镜两端的折射收敛规则（FIX48）、头像与置顶（FIX44）、钱包顶部（FIX48）都不变。
