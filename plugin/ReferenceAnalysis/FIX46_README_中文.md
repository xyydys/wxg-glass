# WeChat Liquid Glass · TEST4 FIX46

版本 `0.4.46-test4fix46`，**以 FIX44 为基础**（FIX45 的透镜改动全部不带入）。18 个源文件与 FIX44 逐字节相同（`tools/audit_fix46_scope.py`）。

## 透镜：在 FIX44 上只改两处

1. **恢复内部底栏的缩小**：透镜下的底栏只被透镜边缘的折射带弯曲，不再跟着放大，中间保持内缩的较小高度，边缘向外弯到完整高度。
2. **修复锯齿和碎边**：轮廓改为解析形状，并按屏幕上的实际变化率做抗锯齿。

其余与 FIX44 相同：折射范围仍按原来的上下比例，网格和透镜参数文件与 FIX44 完全一致。另外，透镜下的底栏**不再做红绿蓝分离**。你说的关不掉的边缘色散就是它：它来自 FIX44 的分通道取样，没有任何开关管它。FIX45 的“透镜内底栏边缘轻微色散”开关也已删除。

## 聊天标题的头像模式

- **读取真实头像**，按顺序：
  1. 首页里这个会话那一行的头像，按名字匹配，单聊、群聊（拼图头像）都能读到；
  2. 聊天里对方消息的头像（单聊）；
  3. 导航栏里的原生头像；
  4. 都没有才用人物占位图。

  每个聊天只读一次并缓存；还没找到时每 1.5 秒重试一次。诊断 `avatarStatus` 写着来源。
- **头像大小可调**：设置 → 聊天头像 → 头像大小（44–120pt，默认 72）。
- **名字胶囊在头像下方**，间隔 6pt，参照 iMessage；不再与头像重叠。
- **描边画在头像图片自己的圆形边缘上**：描边位于裁成圆形的头像图片内侧，贴着图片边缘，颜色、不透明度、宽度、左下 / 右上渐隐都可调（关闭头像玻璃时才有）。
- **置顶栏**：不再用位移变换（那样只移动画面，点击仍在原处，展开后也不跟随）。现在在微信设置置顶栏位置时就加上偏移，真实位置随之下移：点击跟着走，展开、收起时微信重新设置位置，同样会带上偏移。下移距离按置顶栏真实的顶边计算，正好落在名字胶囊下方 6pt。只对 `MMMsgCommonTips` 开头的类挂钩，而且是按类单独添加，不影响其它视图。诊断新增 `pinnedOffset`、`pinnedViews`、`pinnedHookedClasses`、`pinnedCandidates`（导航栏下方看到的视图类名）。如果展开后的列表是另一个类，看这几项就能知道。
