# WeChat Liquid Glass · TEST4 FIX43

版本 `0.4.43-test4fix43`，基于 FIX42。18 个源文件与 FIX42 逐字节相同（`tools/audit_fix43_scope.py`）。冷启动的修复（备用材质底板保留到第一帧、材质层层级检查）和渲染状态记录都保留；拖动手感不变。

## 切换速度

以 FIX42 相邻一格的时长为基准：
- 1→4（三格）= 原来一格的时长；
- 隔一个（两格）= 原来一格的 0.95；
- 相邻（一格）= 原来一格的 0.9。

| | 一格 | 两格 | 三格 |
|---|---|---|---|
| 按下后滑过去 | 0.252 s | 0.266 s | 0.280 s |
| 从静止松手的移动 | 0.243 s | 0.257 s | 0.270 s |

即 时长 = 基准 × (0.85 + 0.05 × 格数)。过程细节不变：同一条缓动曲线，移动约 55% 时达到最大（最透明），约 90 ms 落下、落下结束时正好到达，再 50 ms 收尾。

快速点按时，手指往往在按下滑动的中途就松开了。这时松手动画会按按下时规划好的结束时间落地（距松手至少 0.12 秒），而不是重新按剩余距离计时，所以一次点按从按下到落地的时间就是上表的时长。
