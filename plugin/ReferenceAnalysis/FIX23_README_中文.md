# WeChat Liquid Glass · TEST4 FIX23

版本 `0.4.23-test4fix23`，基于 FIX22。只改“同步”渲染方式的折射质量。回读路径（`WXGBackdrop.m`）、着色器、光学、底栏等 24 个源文件与 FIX22 逐字节相同（`tools/audit_fix23_scope.py`）。

## 同步模式折射为什么不清楚

同步模式靠一张网格让系统渲染服务弯折背景：每个顶点说明“这里显示的像素来自哪里”，顶点之间直线插值。FIX20 用的是 30×17 的规则网格。默认参数（折射 1.15、宽度 10pt）下误差只有 0.2pt 左右；但你的参数是**折射 8.97、宽度 7.7pt**，曲线非常陡，7.7pt 内要把背景推开约 23pt。规则网格在这一圈里只有两三个顶点，跟不上，于是：

| 你的参数，底栏边缘一圈 | 平均偏差 | 最大偏差 | 偏差超过 1pt 的像素 |
| --- | --- | --- | --- |
| FIX20 规则网格（510 顶点） | 1.21pt | 3.95pt（3x 屏约 12 像素） | 57% |
| **FIX23 轮廓网格（1890 顶点）** | **0.022pt** | **0.20pt** | **0%** |

这就是“折射糊、不清楚”的原因。

## FIX23 的做法

- **顶点沿玻璃轮廓分布**：一圈圈平行于边缘的环。环与环的间距按 TEST9 折射曲线的实际弯曲程度计算：曲线弯得越厉害，环越密（目标误差 0.06pt）；两端圆弧按角度细分；直边只需要两端（那里的映射本来就是直线）。最外面还有一圈，覆盖系统连续圆角裁剪多出来的那一点。
- **形状场和折射曲线仍与着色器完全相同**：`WXGRoundedOpticalField` / `WXGCapsuleOpticalField` 与 `WXGOpticalOffset`。
- **按压不再重建网格**：网格用玻璃未缩放的尺寸生成，底栏按压放大时跟着一起拉伸，结果完全相同。只有透镜在变大的过程中重建，用较轻的一档（约 700 顶点）。
- **RGB 色散回来了**：用红、绿、蓝三层背景（同一次捕获），每层只保留一个颜色通道并用自己的网格折射。红色向外取样、蓝色向内取样，偏移量与着色器的 `wxgRGB` 一致（主体 色散×0.85×边缘权重，透镜 色散×1.55×按压）。绿、蓝两层以相加方式叠到红层上，合成完整颜色。
- **透镜上下收窄**（FIX21 的比例和曲线）现在在同步模式同样生效。
- 清晰折射边（模糊覆盖扩展低于 100% 时）同样分成三层。

逐像素回读仍然略好的地方：顶点之间是直线插值（误差已在 0.2pt 以内），以及 TEST9 对按钮按压时的细微放大。

## 设置（设置 → 采样）

- 渲染方式：**同步**
- 同步模式网格折射：开
- **同步模式 RGB 色散**：开（新）。如果同步模式下玻璃整体偏蓝或偏色，说明这台系统上的背景层不支持相加合成，关掉它即可（仍有清晰折射，只是没有色散）。
- 同步模式模糊倍率：按需要调。

## 安装

```bash
cd /var/mobile && unzip -o WeChatLiquidGlass_0_4_23_TEST4_FIX23_flat.zip -d WeChatLiquidGlass_FIX23 && cd WeChatLiquidGlass_FIX23 && chmod +x build.sh && ./build.sh rootless
```

## 请对照

1. 同步模式下看底栏、导航按钮边缘的折射是否清晰，和回读模式比。
2. 色散开／关各看一次，边缘的彩边是否出现、整体颜色是否正常。
3. 按住底栏拖动透镜：透镜里的折射、放大、上下收窄是否跟手。

诊断（每块玻璃 `materialLayers`）：`meshBuilder` 应为 `contour_FIX23`；`bodyMeshVertices`；`bodyMeshAccepted`、`greenMeshAccepted`、`blueMeshAccepted`；`syncDispersionLayers`；`lensMeshVertices`。
