# WeChat Liquid Glass · TEST4 FIX52

版本 `0.4.52-test4fix52`，基于 FIX51（FIX44 + 内缩 + 约 45° 过渡 + 钱包）。只改两端：FIX51 的“按图标范围收敛”整个换掉。

## 你描述的规则，以及录屏里看到的

我把你的 iOS 26 录屏逐帧看过（`ReferenceAnalysis/FIX52_iOS26_*.png`）：
- **第 49–65 帧**：透镜右侧还在底栏直线段上，右沿强烈折射，底栏上下边框“粘”在透镜上，弯进去接到内部缩小的底栏；
- **第 70→74 帧**：右侧越过直线段结束的位置，约 4 帧（透镜只走了约 2pt）就分离完：之后底栏末端的圆弧不再被折射，作为独立的曲线透过透镜可见，“浏览”也不再被拉扯；
- **第 113 帧以后**（停在末端）：透镜里只有内部缩小的底栏和它自己的圆头，与透镜边之间是一道干净的暗缝加一条很细的彩边。同时透镜左侧仍在直线段上，一直保持粘连和过渡。

## 现在的做法

每一侧单独判断：
- **粘连**：这一侧透镜轮廓与底栏上下边框的交点还在直线段上时，折射和 45° 过渡与 FIX51 完全相同。直线段结束之前折射照常进行，不会像 FIX51 那样在图标边缘就提前停掉；
- **分离**：交点一到达圆弧，在 2pt 内完成两件事：
  - 这一侧的折射带降到 1.5pt 的细边，只留一条细彩边，底栏圆头不再被拉扯；
  - 这一侧的 45° 过渡断开，内缩一直延伸到透镜边，因为此时外侧已是圆弧，内外之间没有明显的高度差。

着色器、透镜下的折射网格、点按动画三处用同一条规则。点按动画按目标位置取左端、中间、右端三种网格，预热时就建好。

`ReferenceAnalysis/FIX52_glued_separated_simulation.png` 是按你的设置模拟出的形状：上图为底栏中段，两侧都粘连；下图为末端，左侧粘连、右侧分离，透镜里是内部缩小的底栏圆头和暗缝。

## 验证边界

本环境无法编译 Objective-C / Metal，请以手机端为准。已完成：40 个 C 测试（`-Wall -Wextra -Werror`）。新增 `LensGlueTests`（替换 FIX51 的 `IconSpanTests`），验证：
- 交点到直线段结束前为粘连，越过后为分离，中点正好一半，另一侧不受影响，静止时为粘连；
- 粘连时宽度与 FIX21 逐值相同，分离端为 1.5pt，上下边不变；
- 粘连时过渡与 FIX51 相同，分离时内缩直达透镜边；
- 网格在字段为 0 和底栏中段时逐位 / 逐点不变，末端那一侧几乎不再位移，另一侧不变。

Metal 统一变量结构回到 224 字节（FIX51 新增的 `span` 已删除）。另外：`tools/check_unused_statics.py`（0）；源码中没有 `@available`。
