# WeChat Liquid Glass · TEST4 FIX2

版本 `0.4.2-test4fix2`，从 TEST4 FIX1 修补。保留 TEST9 材质参数、独立透镜与 LUMI 展开后的形变，不重置 `optics.test4`。默认双端输入外观和原三端实验开关保留。

## 本轮修改

- **深浅色**：单色且没有明显明暗层次的位图转为可随外观着色的模板；之前 Already Original 的黑色图标只改 tint 不生效。彩色和有明暗细节的图像保留原图，头像不做此转换。首页手势星标的原图也使用可恢复的模板变体。底栏普通状态优先采用其原生标题的对应颜色。
- **原生转场**：保留 TEST4 完整的图标、返回计数小胶囊和标题排版；导航装饰归属导航控制器的视图。按原控件/图像/标题的 model → presentation 仿射变换与透明度跟随，覆盖进入、退出、半屏返回和取消。原生像素由可恢复的空 mask 隐藏，原控件 alpha、transform、hidden 的动画继续由微信管理；不替换返回手势或它的 delegate。
- **转场生命周期**：前后两页的玻璃同时保留至原生 coordinator 完成；取消后回到真实顶部控制器。完成过的 coordinator 不会因 UIKit 在完成回调里仍返回它而再次绑定。未使用 UIView alongside 动画的 coordinator 也继续等待 completion；from/to 的 didAppear 有明确收尾补充。
- **设置/图片/分享**：打开自身设置时不再主动隐藏整层材质；覆盖位于控制器视图内，随 UIKit 的页面快照和覆盖显隐。整个模态存在期间保留绑定和 drawable，结束后同步。导航式图片页走同一转场处理。失活仍暂停绘制而不清空画面。
- **标题人数**：合并标题视图同一行的多个 UILabel，包括单独显示的群人数，再按原胶囊公式测量。文字或尺寸变化时清空旧的像素居中修正。转场中重布局先清除上一帧的显示变换，再计算模型尺寸，避免将已缩放的 frame 写回下一帧。
- **缓存归属**：按导航栈里的实际页面绑定，不拿临时子控制器覆盖当前路由。原生输入工具由新页面接管时释放上一适配器，并重新读取原生布局，防止两个页面对同一工具保留不同尺寸修改。
- **首页性能**：底栏保留独立捕获与 TEST9 光学/GPU 流程，但捕获前裁去 ROI 外可裁剪子树和本插件图层，避免每次整页层级回读。顶栏绑定扫描只在导航布局、路由、设置或标题变化时执行。增加共享捕获、底栏捕获/绘制、刷新、整次回调分项耗时。

`静止时降低背景采样（15 Hz）` 默认开启。滚动、透镜按压/收回和转场时恢复配置的设备能力上限（最高请求 120 Hz）；该开关关闭后静止时也按原目标采样。画面内独立动画不一定触发滚动状态，关注 GIF/视频背景连续性时可关闭作对比。

## 安装

替换 FIX1/旧主插件，rootful 或 rootless 只选一种 deb，也可使用同名 arm64 dylib；完全退出并重开微信。不要同时加载两份主插件，不必清空材质参数。

Theos 工程（最低 iOS 13）：

```sh
export THEOS=/opt/theos
./build.sh rootless
# 有根
./build.sh rootful
```

## 推荐随包探针

配合 **WeChatGlassProbe TEST3 / WGP3**。主插件 `runtimeMetrics` 是只读、无截图接口，记录当前页/宿主身份、绑定几何、外观、模板标记、标题长度、已呈现状态、输入宿主、采样和 CPU 耗时，以及最近 48 条转场事件；不记录标题或聊天正文。

1. 选择“进入/可取消返回转场”，直接点“跟踪12秒”，做首页 → 聊天、半屏返回后取消，再完成返回。
2. 同样记录聊天 → 群设置 → 半屏返回取消/完成；“设置/图片转场”记录打开 WG、关闭 WG、打开图片和返回。
3. “首页性能”与“聊天页性能”各记录一次相同方式的滚动，不用选点；读指标每秒 4 次，不做视图树抓取。
4. 深浅色问题可以另选有问题的图标后切外观，再抓当前；探针记录 tint、模板模式和图像墨迹平均 RGB。

加号菜单、消息长按菜单、标题下逐条置顶项仍用手动局部/延时坐标抓取，等待这些数据后再加覆盖。本版没有猜测它们的宿主并扩大适配范围。

## 验证范围

16 组 C 测试、24 个 Objective-C 语义检查单元、实际 arm64 编译/签名和包校验见 `VALIDATION.md` 及编译包。12 个核心文件和 11 个布局/渲染/动作方法与 TEST4 逐字节一致；标题宽度公式和默认输入布局保留。

当前没有 iPhone，未实测微信、ThemeBox、Metal GPU 或 FPS。转场/缓存修改已落实到代码并附可定位日志，不能把数值测试、源码比对、编译通过当作真机显示已通过。局部模型层捕获对特殊视频/自绘图层的表现也需要设备验证。默认双端输入原有的光标/换行限制不在本轮被宣称已解决。
