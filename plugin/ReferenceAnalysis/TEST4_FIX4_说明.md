# WeChat Liquid Glass · TEST4 FIX4

版本 `0.4.4-test4fix4`，从已确认两端式有效的 FIX3 继续修补：首页采样开销、下拉后的星标挂载、导航原生按钮闪现、三端式布局，以及置顶条和两个菜单的玻璃覆盖。保留现有材质设置，不需要重调 TEST9 参数。

## 修改及依据

### 首页性能和临时回归原布局

新上传分卷 CRC 通过，98 条事件连续，其中 90 条为首页性能记录。设备是 iPhone XS Max、iOS 15.7、微信 8.0.73。繁忙采样中，底栏独立截图/绘制一段约 17–20 ms，顶部共享采样还要约 6–8 ms；60 Hz 每帧只有 16.67 ms。该日志的回调间隔最长约 214 ms。这是修改前的数据，回调频率也不是 GPU 实际呈现帧率。

- 底栏加入现有共享局部采样，顶部、底部和菜单共用每轮一次的截图预算；裁掉范围外的子树和插件自身图层，避免同轮重复截图。
- 共享背景输入上限为 2x；底栏原来的 Metal 输出、图标纹理、两遍高斯和 TEST9 折射/模糊/透镜算法仍按原分辨率运行。这会改变背景输入的细节，不宣称像素结果与独立 3x 截图完全相同。
- 顶底两个区域轮流采样，因此各区域的背景更新频率可能低于屏幕刷新率。采样总上限仍按设备能力限制到 60/120 Hz，动画和位置跟随由显示回调驱动。实际是否更流畅需同机回测。
- 导航栏暂时隐藏不再当作页面销毁。首页星标按真实 `MainFrameLeftBarView` 的父视图变化重新挂载，保留实例并跟随实际宿主移动。
- 在原生导航布局完成后同步重施遮罩和绑定；完成进入转场时保留已经绑定的目标页面，避免无条件恢复原生返回按钮和数字，再下一轮覆盖。原生可逆转场继续由微信控制。

### 三端式输入

- 左侧材质为正圆；右侧两个图标按实际可见图形测量，图标之间、图标与右胶囊边缘、三段之间默认均为 8 pt。
- 中间胶囊根据右侧所需空间适当收窄。只调整原生 grow/录音宿主的横向空间以及侧边控件位置；不直接写 UITextView、TextKit、光标、文字 inset。文字换行和高度继续由原生布局处理，多行时侧边两端对齐底部。
- 原生听写按钮保留在中段里随宿主布局，继续使用原动作、状态图标、绿色动画和加载控件。按已抓到的结构仅隐藏它旁边的静态底图容器；其余动画子树不再被背景清理连带清除。
- 三端式语音切换、按住说话、滑动取消、表情、发送等仍是原控件。两端式 `WXGInput.m` 和 `WXGInputPolicy.h` 与有效的 FIX3 逐字节相同。

| 位置 | 本版处理 |

## 保留和验证

保留 TEST9 材质参数、独立透镜设置、原呼出/落下与 LUMI 展开形变、底栏几何、聊天返回计数胶囊和标题自适应规则。与 FIX3 对照，22 个源码文件逐字节相同；有意变化清单及哈希见 `Validation/fix4_scope.json`。FIX3 说明保存在 `ReferenceAnalysis/TEST4_FIX3_说明.md`。

18 组 C 数值回归通过，包含 1,200 组三端式几何组合；arm64/arm64e 共 26 个 Apple SDK 语义检查单元通过；实际 arm64 编译链接和签名已完成。详见 `VALIDATION.md`。当前环境没有 iPhone，未执行微信私有控件交互或 Metal GPU，也没有 FIX4 真机帧率结论。

## 安装、自编译和简短回测

替换旧主插件，rootful/rootless deb 只选一种，也可替换同名 arm64 dylib，然后完全退出并重开微信。已有 `optics.test4` 设置保留。探针继续用 WGP3.2，本包不替换探针。

Theos 工程最低 iOS 13：

```sh
export THEOS=/opt/theos
./build.sh rootless
# 有根环境：./build.sh rootful
```

建议先查看以下几项，无需重做之前整套抓取：

1. 首页上下滚动、下拉小程序再收回：星标与玻璃是否一起移动并保留；打开聊天时返回按钮/计数是否还闪原生。
2. 三端式空框和多行：左圆、右侧等距、光标与换行；点听写观察静态底图、原生绿色动画；切换语音长按录音再取消。
3. 置顶折叠/展开、首页加号、消息长按：背景、图标与每个原动作；退出菜单、返回聊天后是否恢复正常。
4. 如首页仍卡，用原 WGP3.2“首页性能”录一段即可。新 runtimeMetrics 增加导航修复/星标重挂次数、宿主父级和位置、局部覆盖状态、共享采样裁剪数；不增加截图或聊天正文。

本次新日志只有性能事件和空目标快照，不能单靠它确认新视图位置；三处覆盖和听写底图采用之前成功保存的局部树。现有资料足够完成本轮，无需先补抓。
