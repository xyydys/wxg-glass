# WeChat Liquid Glass · TEST4 FIX14

版本 `0.4.14-test4fix14`，基于 FIX13，保留 FIX12 输入布局防重入／有界修复。此次只调整底栏返回策略、透镜选中填色与采样遍历；不是满帧或全部真机问题已解决的承诺。

## 诊断结论

上传文件虽然仍叫 FIX11，内部实际版本是 FIX13，系统 26.6，Apple A18 Pro GPU，屏幕最高 120Hz。插件自身底栏统计为背景平均更新 21.8 次／秒、提交约 22.1 次／秒；这些不是逐帧呈现 trace。三个诊断快照的场景读取耗时约 31–35 毫秒，其中几乎全部花在一次完整 `UINavigationTransitionView` 原生截图。

FIX13 的有效区域只占整张图约 18.8%，但 CGContext 裁剪没有阻止 UIKit 处理那整棵导航视图。这说明上版减少像素面积的措施没有触及该设备上的主要开销。没有 FIX4 同设备同场景计时，无法给出 FIX14 相对 FIX4 的倍数结论。

源码对比也确认，FIX4 主要使用临时剪枝后的 `renderInContext` 模型层绘制，并限制每轮采样区域数；后续为视频与转场画面换成原生 `drawViewHierarchy`，但 FIX13 没有在截图前拆开整棵导航树。这是两版实质性的采样路径差异，单调高 FPS 配置无法弥补。此次没有重新引入临时修改原生层级的采样方式。

## 返回显示取舍

已核对官方 Telegram iOS 固定提交。它把 TabBarController 作为自有导航栈第一页，底栏随整页移动，由聊天页自然遮挡；同时管理完整导航手势、页面栈和取消恢复。这不能直接等同于微信 MMTabBar 子视图。详细文件和行号见 `ReferenceAnalysis/Telegram_return_review.md`。没有复制 Telegram 代码，也没有接管微信导航 delegate 或 animator。

采用用户认可的求稳方案：

- 自建底栏持续归属根前景容器，不在原生底栏与其他父视图之间反复搬移。
- 返回目标是四个主 tab 的根页面时，返回一开始显示完整底栏；转场期间不接受底栏触摸。
- 返回完成后保留并恢复点击；取消返回时隐藏。由首页进入聊天／视频号时隐藏；取消进入时恢复。
- 聊天与聊天设置之间不显示首页底栏。系统模态或自身设置覆盖时保留画面、禁用交互；拒绝迟到的 tab 点击提交。
- 原生 MMTabBar 绘制容器保持遮罩，避免原生图标和背景重复显示；实际点击仍通过原生动作转发。旧透明底栏区域不接受触摸。

这是完整前景显示的稳定折中，**有意放弃按页面移动比例局部露出**。本次普通诊断没有视频号返回 coordinator 的完整路径，该场景仍需真机核验，不能据此称两处都已验证通过。

## 透镜颜色

旧 shader 使用 `selectionColor.a × 底栏覆盖率` 给透镜上色，因此恰好只在透镜与底栏重合处留下选中胶囊色。现在静置填色在呼出前 12% 平滑退到零，随后透镜拖动／按压期间不再混入选中胶囊色，收回末段才恢复。首个 Metal 画面前的备用层也用相同规则。

保留原折射、模糊、色散、材质 tint、透镜尺寸和运动。隐藏旧“按压底色不透明度”调节入口，旧存储值仍兼容；静置胶囊的颜色与不透明度仍可调。这里清除的是选中填色，用户设置的玻璃材质底色没有被偷偷重置。

## 采样修改

FIX14 将按玻璃实际取样区域继续拆开安全的导航／页面／滚动容器，再读取相交的内容分支，而不是对整个导航树做一次原生截图后才裁剪。每轮仍处理所有有效玻璃，不用降低更新频率、交替跳过按钮或暂停转场来掩盖开销。输出画布、折射、Gaussian 模糊参数保持原样。

复杂原生绘制、视频和特效不能普遍用手工层绘制替代；会保留必要的原生读取。新的分支指标用于确认旧的导航整树读取是否消失、剩余成本在哪里。实际帧率和低设备改善仍待测量。

## 安装和检查

替换旧主插件，保留原参数，完全退出微信后打开，确认 FIX14。注入用 dylib；越狱根据环境选择 rootful 或 rootless deb，不要同时加载多个主插件。

先不用探针：按住并拖动底栏，查看透镜是否还残留静置胶囊色；然后分别从聊天、视频号返回，测试完成返回和中途取消。再查看首页滚动及进入聊天是否更顺畅。仍异常时导出当前诊断即可，不用重跑整套抓取。诊断文件名已修为 FIX14，现有 WGP4.3 可以继续使用。

本环境无法运行微信／UIKit／Metal 真机。交付的 arm64 iOS 13+ dylib 已交叉编译；arm64e 做语义检查。Metal 保持设备首次使用时编译。验证细节在 `VALIDATION.md`，旧版本命名报告只作历史追溯。

自行编译：设置 THEOS 后运行 `./build.sh rootless` 或 `./build.sh rootful`。
