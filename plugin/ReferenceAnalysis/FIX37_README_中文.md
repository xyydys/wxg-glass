# WeChat Liquid Glass · TEST4 FIX37

版本 `0.4.37-test4fix37`，基于 FIX36。18 个源文件与 FIX36 逐字节相同（`tools/audit_fix37_scope.py`）。

## 图标重叠：真正的原因在着色器

底栏的 Metal 叠加层分两遍画：底板一遍、透镜一遍。底板那一遍走的是普通玻璃的分支，会把**未选中**图标画满整条底栏，透镜下面也画；透镜那一遍再在透镜里画**选中**（填充、绿色）图标。透镜的毛玻璃采样到了底板这一层，于是黑色线框图标被折射、放大后从下面透出来，和绿色图标错开一点——就是你看到的重影，静止的胶囊和按住拖动时都有。这也解释了按压透镜为什么带着底栏的材质。

现在底板那一遍在透镜形状内不画未选中图标，透镜里只有填充的选中图标，透镜外只有普通图标。图标跨在透镜边缘时，里面一半是填充绿色，外面一半是线框，不会叠在一起。

## 落下时的深灰色胶囊

动画在交接时做了淡出，而淡出作用在含有毛玻璃层的图层上。毛玻璃层一旦处在透明度小于 1 的图层里，就不再采样屏幕，而是画成一块平的深色（和 `UIVisualEffectView` 的 alpha 小于 1 一样）。录屏 1.40 → 1.50 秒正是这一下。现在任何含毛玻璃的图层都不做淡入淡出；交接改为：静止状态画好后，在同一次提交里瞬间换过去。两边显示的是同一个胶囊，所以既看不出切换，也不会叠出两层胶囊。

## 切换动画：按你的简单模型

一条按压曲线驱动全部变化：
- 前半程：透镜向标准按压状态放大，选中胶囊色同时逐渐变透明；
- 后半程：从那里缩回静止胶囊，胶囊色同时加回；
- 放大的幅度按距离计算：1→4 放大到标准按压透镜，一格只放大到三分之一，并从那里原路回落（正放、倒放）；
- 不再有落地后的压扁回弹；
- 透镜里是微信的填充选中图标（绿色），透镜外是普通图标；透镜的折射、色散按这次的峰值按压计算。

整段约 0.46 秒，滑行弹簧比上一版略软。

## 按住拖动的形变

更容易触发，也更明显：
- 速度在约 190 pt/s 时就接近饱和（原来 300）；
- 加速、急停的阈值降低到原来的约 60%；
- 拉伸范围从 ×0.78–1.39 扩大到 ×0.70–1.60；
- 持续快速移动时，透镜高度可以压到底栏高度的 90%，比底栏略矮（原来最低等于底栏高度）；
- 形变弹簧更快，过程中的中间形态更清楚。

形变测试已经按新规则更新：持续快速移动时，透镜比底栏矮，但不低于底栏的 86%。

## 顶部按钮

- **切换标签时露出原生按钮**：冷启动日志显示，每次回到首页都会发生 1–2 次绑定修复。原因是切换后为新页面建玻璃的那次刷新是异步排队的，总比微信第一次显示新页面晚一帧以上。现在把切换交给微信之后，立即同步刷新，新页面的玻璃和页面出现在同一次提交里。
- **冷启动**：日志显示首页 +2.78 秒就出现了，但导航玻璃到 +3.52 秒才建好，中间约 0.7 秒是原生按钮。现在启动后 15 秒内，标签首页还没有导航玻璃时，每 0.1 秒主动重试一次，不再等下一次布局通知。底栏玻璃的第一帧（+4.36 秒）要等微信冷启动让出主线程，这期间显示的是备用图标和材质。

## 设置

- 删除了左上 / 右下渐隐（iOS 26 的描边只在左下和右上两条对角渐隐），旧的存储值也会被清零；
- 删除了三种底栏切换时机，现在总是立即切换。

## 编译修正

删掉切换时机设置后，生成分段控件的辅助函数 `WXGSegment` 没有调用者了，在 `-Werror` 下报 unused function。已删除；并新增 `tools/check_unused_statics.py`，以后每次打包前都检查一遍。
