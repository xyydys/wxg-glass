# WeChat Liquid Glass · TEST4 FIX25

版本 `0.4.25-test4fix25`，基于 FIX24。只改了同步模式的网格生成（`WXGMeshRefraction.h`）和诊断标签，其余 27 个源文件与 FIX24 逐字节相同（`tools/audit_fix25_scope.py`）。

## “中心被挖空”和“像素风格”是同一个原因

截图放大后可以看到：
- 输入框左端圆头的圆心、加号按钮的圆心各有一块**没有模糊也没有折射的洞**，直接露出下面的原图；
- 关掉模糊后，玻璃里的字笔画被切断、错位，看起来像像素风，而回读模式的同一处是完整的。

FIX23/24 的网格是一圈圈平行于边缘的环，一直收缩到最里面。对胶囊来说，两端圆头的所有环最后都收缩到圆头的圆心；对圆形按钮，则收缩到正中心。结果在同一个点上叠了 **33–64 个顶点**，还有 64 个以上面积为零的三角形。系统渲染服务不画这种退化的扇形，于是那里就成了洞，洞附近的三角形也把笔画切开了。

## FIX25 的做法

- 环只铺到折射带外 1.25pt。那里的映射已经是“不变形”（主体）或“均匀放大”（透镜），都是直线关系，用什么三角形都完全准确。
- 里面用普通的竖向四边形，从上到下整齐填满（“梯子”）。它比最后一圈环向外多 1pt，两者只在不变形区域重叠，所以没有缝，也没有退化点。
- 测试结果：每个位置只有 1 个顶点（之前 33–64 个）；退化三角形 0 个（之前 64–324 个）；内部映射误差 0.0001pt；边缘折射精度与 FIX23 相同（你的参数下最大 0.2pt）；顶点数还少了约 7%。
- FIX24 的“关闭网格平滑”保留。

## 安装

```bash
cd /var/mobile && unzip -o WeChatLiquidGlass_0_4_25_TEST4_FIX25_flat.zip -d WeChatLiquidGlass_FIX25 && cd WeChatLiquidGlass_FIX25 && chmod +x build.sh && ./build.sh rootless
```

## 请确认

1. 同步模式下，输入框圆头、加号按钮、导航按钮的中心不再被挖空。
2. 关掉模糊和材质覆层色，玻璃里的字应和原图一样完整清晰（比回读模式更锐，因为同步模式用的是原生分辨率）。
3. 诊断：`meshBuilder` 应为 `contour_ladder_FIX25`，`meshSubdivisionSteps` 应为 0。

## 关于参数

你已经确认，折射宽度小于 15、强度小于 20 时没有大问题。宽度和强度过大时，边缘推开的距离会超过小按钮的半径，出现镜像拉伸，回读模式也一样。

本环境无法编译 Objective-C，请以手机端 `./build.sh` 为准。38 个 C 测试通过（`Tests/ContourMeshTests.c` 新增：无聚点、无退化三角形、内部精确）；括号结构检查与范围审计通过。
