# WeChat Liquid Glass · TEST4 FIX55

> 存档：FIX55 没有被采用（用户：和想要的结果差很多；连接曲线和末端吸入都算“粘连”）。FIX56 基于 FIX54，不含 FIX55 的改动。文中的对照图在 FIX55 压缩包的 `ReferenceAnalysis/` 里。

版本 `0.4.55-test4fix55`，基于 FIX54，只改**拖动时**透镜在底栏两端的显示。点按 / 按住时的透镜（渲染服务里的那个）、拖动形变、点按切换、冷启动、钱包、头像、置顶都与 FIX54 相同。

## 原因

我按你截图量出的尺寸（底栏 377.8 × 67.2 pt，透镜 110 × 79.8 pt，内缩 4.4 pt）把 FIX54 的着色器复算了一遍，和截图对得上（`ReferenceAnalysis/FIX55_ends_compare.png` 左列）。

- **末端没有“包进去”**：透镜里的底栏只是整条底栏向内平移 4.4 pt，上下左右都只缩这么多。左右方向几乎等于没缩，而透镜走到末端时右沿还差底栏末端十几 pt，所以内部底栏一直延伸到透镜边，外侧那截底栏也一直露在透镜外。你的猜测是对的：只算了高度的缩小。
- **内外边框错开**：内缩在透镜边 1.25 pt 内完成，等于一个台阶。

## 现在

每一侧单独看“透镜轮廓与底栏上 / 下边框的交点”在哪：

**交点在直线段上（粘连）**
- 外侧边框伸进透镜，以 S 形曲线接到内部缩小的边框：下沉 4.4 pt 就水平走 4.4 pt，平均 45°，最陡约 56°；
- 曲线是在折射之前接好的，再整体被折射和色散；
- 远离交点的上下边与 FIX54 相同（透镜被快速拖动压得比底栏还矮时，那道暗缝随之变浅，矮到约 9 pt 时消失）。

**交点一进入末端圆弧（分离）**，约 0.12 秒内（短弹簧，临界阻尼，略带粘滞）：
- **外侧的底栏末端被吸进透镜**：末端停在透镜最外沿以内 2 pt，透镜更大的圆头把它整个盖住，透镜外不再有任何底栏；底栏的阴影也跟着缩短；
- 透镜里显示内部底栏**自己的圆头**，与透镜边之间是一道缝（中线处 2 + 4.4 = 6.4 pt）；
- 这一侧的连接断开；
- 这一侧的折射范围（底栏和后面的页面）收窄到上下边的宽度（按你的设置 20.26 × 0.305 ≈ 6.2 pt）；
- **图标和文字仍按原来的范围折射**，不会因为收窄突然变形。

分离期间透镜往回退，末端一直贴在透镜里跟着走（这就是“粘滞”：外侧仍然不露底栏）；交点回到直线段时松开，末端约 0.09 秒流回原位，连接恢复。松开后末端只会往外流，不会被透镜带着继续往里缩；快速甩开时，末端每秒最多被多吸 300 pt，不会一下子被扯进去。抬起手指时立即松开，透镜落回胶囊，末端随之流出。

是否分离按透镜**静止时**的位置判断（不看快速拖动后的弹性形变），越过圆弧起点 1 pt 才分离、退回直线段 1 pt 才连接，透镜还必须比底栏高出 2 pt。所以拖到临界点附近停下，不会来回跳；快速拖动、透镜被压扁时也不会分离。

左右两端对称。按截图的位置：截图 1 交点还差 4.4 pt 到圆弧，仍是粘连；截图 2、3、4 都已分离。

## 固定参数（写在代码里，没有加设置项）

| 项 | 值 | 位置 |
|---|---|---|
| 连接从交点往里开始 | 1 pt | `WXG_END_JOIN_START` |
| 连接长度 | = 内缩深度（平均 45°） | 着色器 |
| 分离 / 连接的回差 | ±1 pt（按静止位置） | `WXG_END_HYSTERESIS` |
| 透镜需高出底栏 | 2 pt 分离，低于 1 pt 松开 | `WXG_END_TALL_ON` / `OFF` |
| 末端停在透镜外沿以内 | 2 pt | `WXG_END_MARGIN` |
| 吸入弹簧 | 900 / 60（约 0.12 秒到 90%） | `WXGLensEnds.h` |
| 松开弹簧 | 1600 / 80（约 0.09 秒） | `WXGLensEnds.h` |
| 分离时末端最快再往里吸 | 300 pt/s | `WXG_END_PULL_RATE` |

想调快慢、角度或缝的宽度，直接告诉我数值。
