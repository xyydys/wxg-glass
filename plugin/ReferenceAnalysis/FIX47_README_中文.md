# WeChat Liquid Glass · TEST4 FIX47

版本 `0.4.47-test4fix47`，基于 FIX46。14 个源文件与 FIX46 逐字节相同（`tools/audit_fix47_scope.py`）。

## 透镜

- **“括号”接上了**：透镜内底栏的内缩原来在透镜边缘 1.25pt 内就完成，几乎是一个台阶，看起来外侧边框和内部缩小的边框是断开的。现在内缩在“与内缩深度相同的距离”内完成（按你的设置大约 6pt 横向对应 6pt 下沉），外侧边框以约 45° 的曲线接到内部缩小的边框上，再叠加折射。
- **底栏两端**：透镜的端部伸出底栏末端时，它的折射宽度在 4pt 内迅速降到上下边的宽度，那一块只剩内缩的底栏和一条很窄的、带色散的透镜边框，和上下边一样。底栏中间完全不变：透镜两端仍在底栏内，规则与 FIX44 相同（测试逐点验证）。色散强度不变，只是带宽随之变窄。

## 置顶栏

FIX45 的位移变换和 FIX46 的修改位置都把置顶栏移出了它所在的容器：画面移动了，点击却还在原处，展开也出问题。现在改为给聊天页**增加顶部安全区**（增加量 = 头像和名字胶囊伸到导航栏下方的高度 + 6pt），让微信自己把置顶栏和消息列表排到更低的位置，点击和展开都由微信自己处理。离开聊天、关闭头像模式时恢复。

如果微信的置顶栏不按安全区排版（位置没变），诊断里的 `pinnedProbe` 会列出置顶栏从自身到页面的每一层：类名、位置、是否裁剪、能否点击、手势数，以及增加的安全区和当前安全区。下一步据此调整真正的容器。

## 头像

- **不会再读到语音输入按钮**：“对方消息头像”现在只在消息单元格里找，排除模板图标（语音按钮就是模板图标）和太小的图片。
- **首页会话行**：名字匹配放宽为完全相同，或一方是另一方的开头（备注、表情后缀）。诊断 `avatarProbe` 会写出用什么名字去找、首页是否在、扫了多少行、匹配到几行。如果还读不到，看这一项就知道卡在哪一步。

## 钱包顶部

钱包是微信支付的 Kinda 页面：整页背景是 0.10 灰，内容从导航栏底边（88pt）开始是 0.07，所以导航栏后面露出一条更亮的“背景”。新规则：如果一整屏的不透明背景，下面被从导航栏底边一直到屏幕底部的不透明内容完全盖住，那么它只在导航栏后面露出来。这时把这一条涂成**内容自己的颜色**（只在两者颜色不同时；不直接清除，因为页面后面可能是黑色，浅色模式下会变成黑条）。离开页面时恢复原色。

