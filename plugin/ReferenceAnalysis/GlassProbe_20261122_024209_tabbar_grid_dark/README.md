# iOS 26.6 系统底栏 · 深色网格关键帧

这段 GlassProbe 2 采集长 7.889 秒。探针在抖音宿主中创建了带「微信、通讯录、发现、我」四个标签的系统底栏。画面先记录脚本切换，随后记录手动往返拖动。原包有 211 张 JPEG，以下 9 张保留原图、原始帧号和采集时间。[采集参数](capture.json)

分析按压和回弹可依次看 F224、F371、F436。比较两种拖动方向可并排打开 F241 和 F266，先借助彩色网格观察透镜两端，再看内部图标是否跟着移动。要测量变化持续了多久，可用完整的 [447 帧时间轴](timeline.csv) 和 [396 条触控记录](touches.txt)。

## 读数与坐标

- JPEG 为 880 × 246 px，对应窗口中从 (0, 833) pt 开始的 440 × 123 pt 区域。换算为图片坐标时，横向乘 2，纵向先减 833 再乘 2。另一份静止截图是 1320 × 369 px 的原生 3× 无损图，适合观察静止边缘。[静止 PNG](dump/rest.png)
- 网格每 4 pt 一线，每第五条横线为红色，每第五条竖线为绿色。跨帧量速度时使用采集时间差。触控从 3.80156 s 开始，6.48103 s 抬起。最后一张入选画面是 F436，之后还有十帧时序数据。
- 采集脚本在约 0.6、1.2、1.8、2.4 秒分别将选中索引设为 1、2、3、0。初始索引就是 1，第一次赋值时画面仍可与起始帧相同。
- 时间轴中的透镜位置使用父视图坐标，宽高为缩放前的点数，横纵缩放和变换平移另列。触点使用窗口坐标；触控阶段为 −1 时，触点栏保留最近一次坐标。
