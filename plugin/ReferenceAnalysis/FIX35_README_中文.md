# WeChat Liquid Glass · TEST4 FIX35

版本 `0.4.35-test4fix35`，基于 FIX34。21 个源文件与 FIX34 逐字节相同（`tools/audit_fix35_scope.py`）。

## 触摸别的标签：透镜立即过去，可以左右滑

FIX33 我误读了录屏，改成了“按下时原地浮起”。现在恢复原来的手感：按下时浮起的透镜立即移到手指所在的标签，可以左右滑动。系统渲染只接管**松手之后**的那一段：从透镜当前的位置和大小，滑到目标并落下、压扁回弹。这一段先交给渲染服务，再让微信切换页面，所以微信的卡顿打断不了它。

长按底栏不再打开插件设置。设置入口已经在微信设置里，长按只在那个入口不可用时才作为备用。之前按住透镜久了会误触发，就是这个原因。

## 透镜：纯透明，没有材质

透镜里只有边框和放大的选中图标（绿色），没有任何底色；落下后的胶囊就是选中色本身，和平时画出来的一样。

FIX34 用不透明底色挡住透镜下面的未选中图标，这次换了做法：动画期间，底栏叠加层只画底板，不画图标，所有图标都由动画图层来画。未选中图标那一层挖了一个跟随透镜移动、和透镜同样大小的胶囊形空洞，所以透镜下面不会再有黑色图标透出来；选中图标则只出现在透镜里。动画结束时，叠加层重新画图标，动画图层淡出，两边的图标位置、大小完全一致。

## 冷启动：材质一开始就是目标状态

之前材质覆盖（遮盖色）是 Metal 叠加层画的。冷启动时着色器还在编译，微信又占着主线程，所以一开始只有毛玻璃，没有遮盖色。现在同步模式下，玻璃里多了一层系统渲染的遮盖色（颜色和透明度取自你的材质设置，区分底栏和其余玻璃、浅色和深色），从第一帧就在，等叠加层画出第一帧后再隐藏。底栏的备用图标和透镜仍然在玻璃上方。

## 设置

二级页面（玻璃与透镜）去掉了「完成」按钮。它一直是从上一级推进来的，左上角有返回。
