# WeChat Liquid Glass · TEST4 FIX41

版本 `0.4.41-test4fix41`，基于 FIX40。18 个源文件与 FIX40 逐字节相同（`tools/audit_fix41_scope.py`）。拖动形变与 FIX39/40 相同。

## 冷启动底栏透明：真正的原因

你的诊断里有两个关键值：
- **深色模式**的底栏材质不透明度是 **0**（普通玻璃也是 0）；
- 模糊是 0。

所以只要底栏认为自己处在深色模式，材质就完全透明、也不模糊，只剩折射，看起来就是“非常透明”。

底栏所在的容器挂在微信根视图下面，外观（深色 / 浅色）是从那里继承的。冷启动时微信的页面已经按浅色显示，但根视图那一层还是系统外观（晚上是深色）。直到微信稍后在更上层应用自己的设置，底栏才切到你的浅色材质 #F9F9F9（0.90）。这就是为什么只有冷启动透明，而且之前每个版本都有这个现象，与 FIX35–40 的“材质替身”无关。

现在：每次刷新时，所有玻璃的容器都直接采用**当前页面实际显示的外观**，而不是窗口或根视图的。冷启动第一次建底栏时，就已经是页面的浅色外观了。视频页那些自己指定了外观的按钮不受影响。冷启动日志会记录每一次外观跟随（例如“外观跟随页面：未指定 → 浅色（窗口 深色）”），汇总行里也多了底栏的实际外观。

## 点击切换：在终点前达到最大，到达时落下

FIX40 用的弹簧一开始很快（0.2 秒就走完约 64%），然后慢慢爬，所以透镜早早到了终点，再以最大状态停很久才落下。现在把弹簧换成一段明确的 ease-in-out 滑动（0.52 秒，平缓起步、匀速、减速到达），透镜的大小在同一个时钟上：
- **0.25 秒**：达到静置按压透镜的 90%，此时约走完 58% 的路程，也是最透明的时刻；
- **0.34 秒**：开始落下，此时约走完 82%；
- **0.52 秒**：落成胶囊的同时到达终点；
- **0.60 秒**：短暂收尾，不回弹；
- 选中胶囊色在最大时最透明，落下过程中加回来；描边、放大跟随同一条曲线。
