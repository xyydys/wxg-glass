# WeChat Liquid Glass · TEST4 FIX36

版本 `0.4.36-test4fix36`，基于 FIX35。18 个源文件与 FIX35 逐字节相同（`tools/audit_fix36_scope.py`）。

## 切换动画

- **透镜有折射和色散了**：动画透镜现在有真正的毛玻璃层，用的是你设置里的透镜参数（折射强度、宽度、上下收窄、放大、按通道色散）。它折射的是透镜下面真实的画面：与底栏重叠的部分是带材质的底栏，伸出底栏的上下部分是没有材质的页面。
- **图标改色，不再换图**：透镜移动时，透镜里的图标是同一套图标改成选中色（形状与外面完全一样），所以不会出现两套形状叠在一起；透镜落下成胶囊的那一刻，才换成微信的选中图标，和原生点按时一样是瞬间切换。
- **不会再出现旧画面**：动画期间底栏的 Metal 叠加层整体隐藏，材质由系统渲染的遮盖层顶替，所有图标都由动画层来画。结束时先画好静止状态，确认画好才显示出来，再让动画层淡出。截图里“微信(3559)”那种左右错开的重影，就是旧的一帧叠在新画面上造成的，现在不会再出现。
- **速度稍慢**：弹簧调软一些，滑行约 0.28 秒，整段约 0.56 秒。

## 按压时的透镜

伸出底栏上下的那部分透镜不再盖材质，是透明的折射色散透镜；与底栏重叠的部分仍然显示底栏自己的材质，底栏不会一起变透明；边框、色散、折射不受影响。原因是在关闭“边缘减弱”时，着色器给透镜伸出底栏的那一圈也加了整层材质。

## 冷启动

- **底栏图标错位**（第一个变成“我”，其余是内置符号）：图标是按它在原生底栏里的横向位置分配到各标签的。冷启动时微信的四个按钮还没排开，都挤在最左边，于是全部被分到第一个标签，第四个“我”的图标最后写入。现在按图标所属的原生按钮来分配，并且只在四个按钮真正排开之后才读取。
- **默认图标改为微信自己的**：每次完整读到微信图标后，存到本地缓存（浅色、深色分开）。下次启动从第一帧起就用这套图标，不再出现内置符号。主题插件换了底栏图标，读到新图标后缓存会跟着更新。全新安装后的第一次启动还读不到缓存，从第二次起生效。
- **冷启动日志**：诊断新增 `runtime.coldStartLog`，记录加载后 30 秒内每一次变化：页面、导航玻璃有几块及各自是否就绪、绑定修复次数、底栏玻璃是否就绪和画出首帧、图标读取状态（读到几个、来源、按钮是否已排开）。右上角回到原生的问题我还不能确定原因，请冷启动后导出诊断发我，看这一项就能对上。
