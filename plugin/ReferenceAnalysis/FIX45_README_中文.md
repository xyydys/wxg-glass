# WeChat Liquid Glass · TEST4 FIX45

版本 `0.4.45-test4fix45`，基于 FIX44。16 个源文件与 FIX44 逐字节相同（`tools/audit_fix45_scope.py`）。

## 透镜内的底栏

**内部底栏变小的效果恢复了。** 透镜下的底栏本来就比外侧略矮（内缩）。FIX44 让它按透镜的完整映射取样，其中包括放大，这一放大正好抵消了内缩。现在底栏只被折射带弯曲、不再被放大：中间保持内缩的较小高度，靠近透镜边沿的地方，边缘沿曲线向外延伸到完整高度，再经过折射和色散，形成你说的“括号”一样的空腔。

**折射范围和色散改为按“底栏内 / 底栏外”连续变化。** 之前按透镜边沿的方向（上下窄、两端宽），到了底栏两头，透镜伸出底栏，底栏末端反而落进最宽的折射带，被卷进去（你图里那样）。现在：
- 透镜边沿在底栏内：用完整的折射宽度；
- 在底栏外（上下伸出的部分、伸出底栏两头的部分）：用“上下比例”那个值；
- 两者之间在底栏轮廓附近 4pt 内平滑过渡；
- **色散也按同一比例变化**（之前色散强度固定不动）。

折射的毛玻璃（网格）和透镜里的底栏用同一条规则。底栏中段的效果与之前相同；只在两头，透镜伸出底栏的部分变窄，底栏末端不再被卷进去。

**锯齿、碎边**：透镜内的底栏轮廓改用解析形状（不再取样粗糙的距离纹理），并按屏幕上实际的变化率做抗锯齿，被拉伸或压缩的地方也是平滑的边。

**新开关「透镜内底栏边缘轻微色散」**（设置 → 按压透镜，带强度，默认关）：透镜内底栏的边缘沿法线方向做轻微的红蓝分离，随按压出现，静止胶囊不受影响。

## 聊天标题的头像模式

设置新增「聊天头像（标题头像模式）」一组：
- **头像背后显示玻璃**：开启时与之前相同；关闭后头像按原玻璃大小（直径 60pt）直接显示；
- 关闭玻璃时可以加一圈描边：颜色、不透明度、宽度、左下 / 右上渐隐，与其余边框同一种绘制方式；
- **置顶栏自动下移**：头像和标题胶囊会伸到导航栏下面，盖住微信的置顶栏（`MMMsgCommonTipsView`，就在导航栏正下方）。现在按两者的重叠量把它整体下移，再留 6pt 间距。用的是位移变换，点击区域跟着一起移动，点哪里就是哪里。退出头像模式或离开聊天时恢复原位。

## 编译相关

网格参数结构末尾加了 4 个字段（全为 0 时等于旧行为）。你的编译开着 `-Wextra`，按位置初始化缺字段会报 `-Wmissing-field-initializers`，所以 `WXGGlassView.m` 和两个网格测试文件在文件内关闭了这一条警告；其余文件不受影响。测试脚本同样用 `-Wall -Wextra -Werror` 编译，先复现了这个错误，加上后才通过。
