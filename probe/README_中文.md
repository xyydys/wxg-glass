# 玻璃探针（GlassProbe）

一个独立的小 dylib，不依赖任何钩子库。注入到**高系统（iOS 26）上能显示原生玻璃的 App** 里（比如装着高系统玻璃插件的抖音），用来把系统原生玻璃的真实像素和图层结构抓回来，给低系统的仿制做依据。平时什么都不做，只有点了它的悬浮按钮才工作。

## 用法

1. 把 `GlassProbe.dylib` 注入目标 App（和注入别的 dylib 一样），打开 App。
2. 两秒后右侧出现一个蓝色的“探”按钮（可以拖动），点它：
   - **① 自动采集**（约 3 分钟，全屏黑底自动翻页，别碰屏幕）：原生玻璃放在一组已知的背景上（纯黑 / 白 / 几档灰 / 截图里那种灰蓝 / 红绿蓝黄 / 彩虹渐变 / 明暗渐变 / 黑白对半 / 细网格 / 彩色斜条纹），每个场景拍 1 倍和放大 8 倍（整个场景做变换放大，屏幕上每 pt 24 像素），深色、浅色各一遍。结束后弹出分享，把 zip 发回来。
   - **② 导出结构**（约 15 秒）：样本玻璃的视图树、图层树（私有图层类的全部属性、滤镜及其参数、效果对象）、图层自带的贴图（存成 PNG）、整棵图层树的归档和 CAML、系统里所有和玻璃有关的类（属性、方法）、CAFilter 的全部类型。结束后同样分享 zip。
   - **③ 手动截图**：只有当 ① 的结果提示“没抓到玻璃”（或者打开图一看玻璃是空的）才需要。它把最关键的 28 个场景一张张显示出来，每张等一秒后按电源键＋音量键截图，点右半屏下一张，长按结束。把相册里的截图**原图**发回来（不要压缩、不要放大裁剪）。
   - **分享已有结果**：之前的结果都还在 App 的临时目录里，可以再分享一次。
3. ①、② 都做一下，两个 zip 都发回来。浅色 / 深色它自己切，不用管系统外观。

## 注意

- 采集前把手机的“降低透明度”“增强对比度”“低电量模式”都关掉，亮度无所谓（它们会改变玻璃的样子；探针会记下当时的状态）。
- 探针窗口在最上层，不影响 App 自己的操作；“隐藏探针”后重启 App 才会再出现。
- 抓完就可以把它从 App 里去掉。
